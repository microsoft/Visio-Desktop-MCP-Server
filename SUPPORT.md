# Help and feedback

Use this repository's **Issues** tab for questions, bugs, and feature requests.
Search existing issues first.

For a bug, include:

- Server package version, Windows version, Visio version, and AI client.
- What you asked, what happened, and what you expected.
- Minimal steps to reproduce, with sanitized logs or a screenshot if useful.

Do not post confidential drawings, personal data, credentials, or unredacted logs.
Use a small, non-sensitive example where possible.

Report security vulnerabilities privately using [Security](SECURITY.md), not a
public issue.
